# 可视化首次安装

下载并双击 [Windows 安装向导](https://github.com/acejunnan/edgebox/releases/latest/download/EdgeBox-Setup-Windows.exe)。
程序会在本机浏览器打开安装窗口，仅监听 `127.0.0.1`，不在网络上提供安装服务。
其他工作站版本见 [Releases](https://github.com/acejunnan/edgebox/releases)。

## 用户操作

1. 小盒插上有线网络并通电，从路由器设备列表查到它的局域网 IPv4。
2. 窗口填写 VPS 公网 IPv4 和小盒 IPv4。
3. 默认使用 root、SSH 端口 22，以及本机 `~/.ssh/id_ed25519`、`id_rsa`。
   使用其他账号、端口、密码或加密私钥时，展开“登录设置”填写。非 root 用户须已有免密 sudo。
4. 点击“检查连接”，通过云控制台或已信任的 SSH 记录核对两端主机指纹。
5. 勾选确认并点击“开始安装”。等待验证通过，复制私人链接导入支持 VLESS + REALITY 的客户端。

**仅填写两个 IP 的前提是本机已有相应 SSH 密钥登录权限。**
IP 地址本身不能授予管理员权限。私钥解密口令或登录密码仅用于此次 SSH 登录，
不保存为配置，不出现在进度记录中。默认密钥查找不读取用户 SSH config 或 SSH agent；
其他私钥请在登录设置中填写文件路径。

窗口打开前生成随机本机会话令牌，防止其他网页调用安装接口。
确认指纹之前只读取 SSH 主机身份，不发送登录密码，也不安装或修改远端配置。
后续连接固定使用已确认的 Ed25519 主机公钥；指纹变化会停止连接。

## 向导自动完成的工作

- 检查两端的系统、WAN 默认路由、已有安装及资源冲突，保存变更前快照。
- 从固定源码提交安装依赖、编译和准备本机独立 WireGuard 密钥。
- 在小盒生成独立 Ed25519 管理密钥，VPS 创建受限的专用隧道账户；
  默认反向端口为 VPS `127.0.0.1:22001`，占用时停止。
- 验证 sshd 有效配置未改变管理员登录策略，为管理配置设置十分钟独立回退计时器。
- 新建一次经 VPS 反向端口进入小盒的 SSH 登录，验证后保存管理通道。
- 自动交换两端公钥、暂存数据配置，并在独立 systemd 定时回退保护下启动。
- 通过临时本地 Xray 测试客户端，验证实际 VLESS → VPS → WireGuard → 小盒 → Internet
  的出口 IPv4 与小盒直接查询一致；再检查 WAN 默认路由和新建反向 SSH。
- 验证通过才提交两端开机启动配置。数据步骤失败时立即回退，已验证的独立管理通道保留。

未能立即清理时，远端定时器仍会独立执行回退；程序退出或浏览器断开不会取消定时器。
窗口的成功状态需要真实代理出口测试，不能仅凭 WireGuard 握手判定。
此流程校验 TCP/HTTPS 出口；UDP、不同客户端、重启及现场运营商网络仍需部署后验收。

## 适用条件

- VPS：AMD64 Debian/Ubuntu、systemd、Python 3.9+、可用 SSH，以及可以访问 GitHub、Go 和软件源的网络。
- 小盒：已装好 64 位 Debian/Armbian，具备 systemd、Python 3.9+、SSH 和普通 IPv4 WAN 默认网关。
- 小盒接上线缆即能正常联网；不处理酒店认证、Wi-Fi 上网设置、拨号、刷机或磁盘分区。
- VPS 云安全组和现有防火墙需事先允许 TCP/443、UDP/51820 和 SSH 管理端口。
  安装器不清空防火墙，也不能替用户操作云厂商安全组。
- 首次部署一台 VPS 与一台小盒；保留资源和冲突检查见[高级安装教程](INSTALL.zh-CN.md)。
- VPS sshd 须通过 Include 加载标准 `sshd_config.d`；向导验证专用账户的有效限制后才 reload。
  小盒和 VPS 现有 SSH 管理员登录方式保留；隧道账户单独强制公钥认证。

已有 EdgeBox、管理账户、同名配置或上次安装留下的现场时会停止，不支持覆盖升级。
登录信息填错可以返回连接设置重新检查；已有部分安装文件时请先检查快照，
不要通过删除密钥或绕过冲突检查来强行重试。

本次通过了安装顺序、失败回退、SSH 主机指纹读取、会话鉴权和输入验证的自动测试。
干净 VPS/Armbian 上的全流程实机安装尚未验收，不能将模拟测试视为实机部署通过。
Web 控制台、管理热点和应用 OTA 仍是独立可选功能，不由此首次安装向导自动启用。

开发运行：`go run ./cmd/edge-setup`。可用 `-no-browser` 只打印本机地址；
发布版本固定源码提交，开发运行默认查询 GitHub main 并固定该次安装的提交。
